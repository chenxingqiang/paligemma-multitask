## 数据集规模与标注

本数据集包含874张图像，使用PaliGemma格式进行标注。标注关注两种主要缺陷类型：
1. 空洞 (void)
2. 裂缝 (crack)

## 预处理

对每张图像应用了以下预处理：
* 像素数据自动方向调整（去除EXIF方向信息）
* 调整大小至640x640（拉伸）

未应用图像增强技术。

## PaliGemma格式

本数据集的标注采用PaliGemma特有的格式，这种格式既支持位置识别，也支持多模态理解：

```json
{"image": "sample_image.jpg", "prefix": "detect void ; crack", "suffix": "<loc0123><loc0456><loc0789><loc0012> void"}
```

此格式有助于训练模型同时理解视觉内容和文本指令，使模型能够：
1. 检测特定类型的缺陷
2. 定位缺陷的精确位置
3. 生成关于缺陷的描述性文本

## 模型适应性

此格式特别适合训练和微调以下类型的模型：
* PaliGemma多模态模型
* 其他视觉-语言模型
* 结合了对象检测和文本生成的混合模型
